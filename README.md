# portugal

A plain static site — no build step, no framework, no `package.json`.

- Open `index.html` normally to view the scrapbook.
- Open it with `?edit` in the URL to launch the built-in editor.
- `photos.json` is the published data (captions, page layout, cover text) that the site reads on load.
- Photos referenced by `photos.json` live in `photos/`.
